# Package reference

Per-package detail moved verbatim out of `CLAUDE.md`'s Monorepo Layout table. `CLAUDE.md` keeps a one-line row per package; this file holds the full text. Per-job detail lives in [`jobs.md`](jobs.md).

## `@wxyc/enrichment-worker`

Path: `apps/enrichment-worker/`

Long-running CDC consumer: claims new flowsheet track rows (`metadata_status='pending'`) and enriches via LML. N×N idempotent-claim (BS#892 / Epic C C2). C6 (BS#895) cron is the gap-recovery safety net. Track-context-gates every LML match on `isTrustedLmlTrackContextMatch` (BS#1359, refined BS#2217, `@wxyc/lml-client`) — `direct`/`compilation` auto-persist outright; a row-less `alternative` resolution (`library_item.id === 0`) also auto-persists when its title corresponds to the requested album, otherwise it and every other same-artist substitution route to the no-match arm. BS#1978: `ENRICHMENT_SUPPRESS_LML_BUDGET` (default off, `'live'` lane only) — see [`docs/env-vars.md`](env-vars.md).

## `@wxyc/database`

Path: `shared/database/`

Drizzle ORM schema, client, migrations, ETL utilities. One **subpath** export besides the barrel: `./streaming-merge-sql` (BS#2693), the shared streaming-column conflict-set SQL builders. It is a subpath and not a barrel re-export because the barrel re-exports `client.ts`, which throws at import time on missing DB env vars, and these builders must be importable — and `require`-able as compiled CJS by a `.spec.js` — without a database. Adding a subpath here takes the same four coordinated edits as `@wxyc/observability`'s `./metrics` (see the `@wxyc/observability` section below), plus `splitting: false`. Rationale, the drift guard on its locally-restated status union, and the reason a type-level assertion must not live in `tests/**` are all in that module's header — single home, don't restate them here.

## `@wxyc/lml-client`

Path: `shared/lml-client/`

HTTP client for library-metadata-lookup (LML). Single chokepoint — `lookupMetadata` wraps `Sentry.startSpan` + `Semaphore(5)` + `TokenBucket(50/min)` mirroring LML's Discogs ceilings (BS#906/G4). Used by `apps/backend` runtime path and `jobs/flowsheet-metadata-backfill`. Every caller-aware method is classified by a `caller`-keyed traffic-class policy (`caller` → class → timeout/budget; BS#1826) — see [`docs/env-vars.md`](env-vars.md#bslml-caller-classification-bs1826) + `shared/lml-client/src/policy.ts`. BS#1748: the runtime `defaultLimiter` bounds its pre-admission queue wait (`LML_LIMITER_MAX_QUEUE_WAIT_MS`, 5 s) and carries a **per-instance** circuit breaker (`circuit-breaker.ts`; never module scope — the BS#955 leak hazard) so a saturated LML fast-fails to the empty `GatedLookupResponse` shed shape (`outcome: 'shed_limiter_saturated'` / `'shed_breaker_open'`) instead of hanging; job limiters keep the unbounded shape.

## `@wxyc/observability`

Path: `shared/observability/`

Cross-container observability primitives, consumed by `apps/backend`, `apps/auth` and `apps/enrichment-worker` so every container applies byte-identical implementations. Package root (BS#2089): Sentry transaction/span filter predicates — drops liveness-route transactions (`/ok`, `/healthcheck`) and Express middleware bookkeeping spans, loaded eagerly at Sentry preload via each app's `instrument.ts` (`node --import`). The filter only runs because backend's and auth's `Sentry.init` pin `traceLifecycle: 'static'` (Sentry 11's default span streaming never calls `beforeSendTransaction`, BS#2948); a new preload that wires the filter needs the pin too. Also at the package root, `SENTRY_DATA_COLLECTION` (BS#3004) — the `dataCollection` option every app preload passes to `Sentry.init`, spelling out Sentry 10's no-options posture (no `userInfo`, so no end-user IPs; IP-bearing headers denied; no HTTP bodies) because Sentry 11 made all of them default-on and removed `sendDefaultPii`, which is now a silent no-op; every field must stay spelled out, since one left out falls back to the permissive default. Also at the package root, `warnIfReservedAwsCredentialsPresent` (BS#2532) — called right after `.env` loads in all three preloads (`apps/backend`, `apps/auth`, `apps/enrichment-worker`; backend and auth load it with `import 'dotenv/config'` as their first import, because ESM evaluates every import before a body-level `config()` and `@wxyc/lml-client` reads its limits at module load, BS#2949), warns once per process when `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` / `AWS_SESSION_TOKEN` / `AWS_PROFILE` is set, the four names that top the SDK credential chain and shadow the EC2 instance role (BS#2518), matching `set-ec2-env-var.yml`'s deploy-time rejection list. It belongs at the ROOT, not a subpath: the preload is the only call site that runs in every container regardless of what the container goes on to do, and it stays barrel-safe by reading `process.env` and importing nothing. `./metrics` subpath (BS#2169): a generic buffered CloudWatch metric emitter (`createBufferedMetricEmitter` — buffer/coalesce/flush-on-interval-or-size/swallow-on-failure), extracted from the machinery duplicated between `apps/backend/middleware/responseMetrics.ts` (BS#845) and `apps/backend/services/sse/sse-metrics.ts`. Three consumers as of BS#2191, which finished the migration the extraction left undone: `apps/auth/auth-rate-limit-metrics.ts`, `responseMetrics.ts`, and `sse-metrics.ts`'s four counters — but NOT `sse-metrics.ts`'s `SSE/ClientCount` gauge, which is sampled rather than recorded, is not additive (the emitter coalesces by summing), and needs a companion emitted even at `total === 0`. Two coalescing invariants a new consumer depends on: `unit` is part of the coalesce key (same name + dimensions but different units are separate datums, never summed under whichever arrived first), and the companion setting is rank-merged across a coalesced group rather than first-wins. **`emitDimensionlessCompanion: 'perEntry'` (= `true`, N + N) and `'aggregated'` (N + 1 summed across slices) agree only under `Sum`** — switching a live metric between them silently rescales every Average/Maximum/SampleCount alarm on it. `flushIntervalMs: null` (caller owns the cadence) and `logPrefix` exist for the same reason: a migrated call site's published shape or log grep depended on them. `flush()` joins any in-flight size-triggered send rather than resolving early against the already-drained buffer — that is the contract `apps/auth`'s SIGTERM handler depends on, since the flush timer is `unref`'d on a 30 s interval and a deploy would otherwise drop a full window. Also exports `createCloudWatchClient` (BS#2533) — the fleet's ONLY `new CloudWatchClient(...)`, pinned to `credentials: fromInstanceMetadata()` so a stray `AWS_ACCESS_KEY_ID` can't outrank the `wxyc-ec2-backend` instance role the way the SES credential did for 105 days in BS#2518; `sse-metrics.ts`'s gauge keeps its own client INSTANCE but builds it through that function, and `tests/unit/observability/cloudwatch-credentials.test.ts` fails if a second construction site appears. The corollary is that nothing off EC2 can publish, so all three opt-out env vars are now actually set in the compose profiles, the GHA workflow and `.env.example` rather than merely recommended in `docs/env-vars.md`. **The `./metrics` subpath is a deliberate second tsup entry, never re-exported from the barrel** (`src/index.ts`) — re-exporting an AWS-SDK-backed emitter from the barrel would eagerly load `@aws-sdk/client-cloudwatch` at process preload in every image that loads the barrel. Adding a subpath here needs four coordinated edits, not just the `exports` map: a tsup `entry` array addition, a tsup `external` addition for the subpath's own third-party deps, a `jest.unit.config.ts` `moduleNameMapper` entry (the bare-specifier mapping does not also match a subpath), and a `tests/tsconfig.json` `paths` entry (ts-jest's `moduleResolution: "Node"` ignores `exports` maps entirely, unlike the apps' own `bundler` resolution).

## Database (`shared/database`) notes

**Correlated select fields:** inside a select-field `sql` fragment, reference the outer row's column only through `outerRef(column)` (`apps/backend/utils/sql-fragments.ts`). A bare column in a single-table select renders unqualified and binds to the subquery's own table, silently.
